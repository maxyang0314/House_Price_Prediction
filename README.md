# 台灣房價預測（Taiwan House Price Prediction）

## 1. 專案介紹

本專案使用台灣不動產實價登錄資料，透過機器學習回歸模型預測房屋成交總價，並以平均絕對誤差（MAE）評估模型表現。

## 2. 資料集

| 資料集 | 資料筆數 | 用途 |
|---|---:|---|
| Train | 455,787 | 模型訓練 |
| Validation | 11,994 | 模型驗證 |
| Test | 47,073 | Kaggle 預測 |

- **預測目標：** 總價元
- **輸入特徵：** 縣市、行政區、建物面積、樓層數、房廳衛數、建物型態、交易日期及車位資訊等，共 19 個特徵。

## 3. 資料前處理

- 移除無法轉換成有效房價的訓練資料。
- 使用中位數填補數值缺失值，使用「未知」填補類別缺失值。
- 對類別特徵進行 One-Hot Encoding。
- 從地址擷取縣市，並將交易日期轉換為西元年及月份。
- 排除缺失值過多或較難直接使用的欄位。

## 4. 模型與實驗結果

使用 **Random Forest Regressor** 建立房價預測模型。

主要參數：`n_estimators=100`、`max_depth=20`、`min_samples_leaf=2`。

| 評估指標 | Validation 結果 |
|---|---:|
| MAE | 1,111,971.26 元 |
| RMSE | 3,281,817.43 元 |
| R² | 0.9323 |
| 訓練時間 | 792.54 秒 |

模型平均預測誤差約為 **111.2 萬元**。後續可透過特徵工程及其他回歸模型改善預測表現。

## 5. 執行方式

安裝套件：

```bash
python -m pip install -r requirements.txt
```

將 Kaggle 資料集放入 `data/` 資料夾，執行：

```bash
python main.py
```

程式將自動完成資料前處理、模型訓練、驗證評估，並產生 `submission.csv` 用於 Kaggle 提交。
